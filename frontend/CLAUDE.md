# Moment Frontend

React 19 + TypeScript + Vite 기반 웨딩 초대장 플랫폼 SPA.

## Quick Commands

```bash
npm run dev       # 개발 서버 (port 3000, /api → localhost:8080 프록시)
npm run build     # 프로덕션 빌드 (tsc -b && vite build)
npm run lint      # ESLint 검사
npm run preview   # 빌드 미리보기
```
